
# LabX BASIC: Automating with CSV and JSON Data

## Objective
Practice reading, processing, filtering, and writing CSV and JSON data using Python.

## Features
- Read sales data using csv.DictReader.
- Calculate total sales and average item price.
- Filter sales where Amount >= 100.
- Write filtered sales and a summary row to a CSV file.
- Read inventory data using json.load.
- Update stock levels for existing products.
- Add a new product and save the updated JSON.

## Project Structure
- src/: CSV, JSON, and utility modules
- data/: Input and output data files
- main.py: Main program

## How to Run
1. Open a terminal in the project directory.
2. Run python3 main.py.
3. Check the output files inside data/.

## Dependencies
Python 3. No third-party packages are required.
